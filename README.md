Nexxus AI (Social-Media-Blocker)
Private, local-first study companion with a distraction-resistant focus timer and a local Llama 3.2 tutor.

Features
Self-study timer — custom minutes/seconds, fullscreen lockdown, session logging
Dashboard — study planner, streaks, daily minutes, weekly focus chart (all local)
AI Tutor — uses local Ollama + llama3.2, context from your uploaded notes/code
MCQ challenge — AI-generated one-question retention check
PWA — installable from supported browsers
Browser extension — redirects social sites to the dashboard while focus mode is on
Desktop companion — system-wide blocking via the hosts file (requires admin/sudo)
Youtube video-suggest video as per users request
